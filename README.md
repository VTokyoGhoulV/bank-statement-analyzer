# Bank Statement Analyzer

Программа для анализа банковской выписки в Excel. Считает расходы и доходы, ищет операции и сохраняет результаты в JSON.

**Стек:** Python 3.14, pandas, openpyxl, requests, python-dotenv, pytest, Poetry.

## Возможности

- Сводка расходов и кешбэка по картам, пять крупнейших операций.
- Расходы и доходы по категориям за выбранный период.
- Расчёт потенциального кешбэка и суммы для «Инвесткопилки» при округлении покупок.
- Поиск по описанию операции, номеру телефона и переводам физическим лицам.
- Отчёты по категории, дням недели, рабочим и выходным дням.
- Курсы валют через APILayer и цены акций через Twelve Data с кэшированием на день.

Расходами считаются отрицательные суммы, доходами — положительные. Неуспешные операции исключаются из расчёта расходов; для кешбэка и «Инвесткопилки» используются операции со статусом `OK`.

## Запуск

Нужны Python 3.14 и Poetry. Команды ниже — для PowerShell.

```powershell
git clone https://github.com/VTokyoGhoulV/bank-statement-analyzer.git
cd bank-statement-analyzer
poetry install --no-root
Copy-Item .env_example .env
Copy-Item data/MyOperations.example.xlsx data/MyOperations.xlsx
```

`MyOperations.example.xlsx` содержит вымышленные операции. Вместо него можно положить свою выписку в `data/MyOperations.xlsx`. Рабочая выписка исключена из Git.

Ожидаются столбцы: `Дата операции`, `Дата платежа`, `Номер карты`, `Статус`, `Сумма операции`, `Валюта операции`, `Категория`, `Описание`.

Для курсов валют и акций укажите в `.env` ключи `CURRENCY_API` (APILayer Exchange Rates Data) и `STOCK_API` (Twelve Data). Без ключей эти разделы будут пустыми, остальная аналитика работает.

Валюты и акции выбираются в `data/user_settings.json`:

```json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL"]
}
```

Запустите из корня проекта:

```powershell
poetry run python -m src.main
```

По умолчанию расчёты используют текущую дату. Период, текст поиска, категорию и шаг округления можно изменить в блоке запуска `src/main.py`.

Для `range_type` доступны `W` — неделя, `M` — месяц, `Y` — год, `ALL` — все операции до выбранной даты. Для `limit` — округление до 10, 50 или 100 рублей.

## Результаты

- `data/views/` — сводки по картам, расходам и доходам.
- `data/services/` — результаты поиска, кешбэк и «Инвесткопилка».
- `data/reports/` — отчёты по категориям и дням недели.

Программа создаёт JSON-файлы; отдельного веб-интерфейса нет.

## Тесты

```powershell
poetry run pytest
poetry run pytest --cov=src
```

Тесты проверяют обработку выписки, расчёты, поиск и сохранение отчётов. Обращения к внешним API подменяются.

## Ограничения

- Импорт рассчитан на перечисленные названия столбцов, а не на любой формат банковской выписки.
- Если даты в примере не совпадают с выбранным периодом, часть отчётов будет пустой.
- Папки `data/cache`, `data/logs`, `data/reports`, `data/services` и `data/views` должны существовать. В репозитории они сохранены с помощью `.gitkeep`.
- Загрузка курсов и акций зависит от API-ключей и доступности внешних сервисов.
- Отчёты содержат данные исходной выписки. Рабочая выписка, результаты, логи и `.env` исключены из Git.
